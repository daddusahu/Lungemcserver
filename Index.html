How To Join Lunge MC

Choose your Minecraft edition, copy the server details, and jump into the adventure.

☕ JAVA EDITION

💻 Java Players

For Minecraft Java Edition on PC. Add the server using this address:

play.lungemc.fun:20005

Server address includes the port 20005.

1Open Multiplayer in Minecraft.
2Choose Add Server and paste the address above.
3Click Join Server and have fun!
🎮 BEDROCK EDITION

📱 Bedrock Players

For Minecraft Bedrock on mobile, Windows, and compatible consoles:

play.lungemc.fun
Port
20005
1Open Play, then go to the Servers tab.
2Choose Add Server.
3Enter the address and port shown above, then connect.

⛏️ PLAY FAIR • SMP RULES

⛏️ Minecraft Server Rules

Please follow these rules to keep our community fair and welcoming.

Rule 1: Respect All Players

Do not harass, insult, threaten, or intentionally ruin another player's experience.

Rule 2: No Cheating or Hacked Clients

Hacked clients, unfair modifications, cheats, or tools that provide an unfair advantage are strictly prohibited.

Rule 3: No Exploiting Bugs

Do not abuse glitches, bugs, duplication exploits, or unintended server mechanics. Report them to staff.

Rule 4: No Griefing or Stealing

Do not destroy, damage, or steal from another player's builds, items, or property without permission.

Rule 5: No Scamming

Scamming, deceptive trades, or intentionally misleading players during transactions is prohibited.

Rule 6: No Unapproved Advertising

Advertising other Minecraft servers, Discord servers, or unrelated services without staff permission is not allowed.

Rule 7: No Lag Machines

Do not intentionally create machines, farms, redstone systems, or setups designed to cause server lag or performance issues.

Rule 8: No Ban Evasion

Do not use alternate accounts or other methods to bypass a punishment or ban.

Rule 9: No Inappropriate Builds or Names

Inappropriate, offensive, or harmful builds, skins, usernames, or structures are not allowed.

Rule 10: No Real-World Trading

Buying or selling in-game items, accounts, ranks, or currency for real money outside of officially approved methods is prohibited.

Thank you all for being a part of our community! ❤️
